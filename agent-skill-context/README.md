# Agent Skill Context

This directory is the master local context layer for agent skills discovered under `%USERPROFILE%\Projects`.

It is generated by `..\scripts\sync_agent_skill_context.ps1` and is meant to stay small, portable, and safe to sync. The generated files list where skills, agent instruction files, and Qoder repowiki context live; they do not copy every skill body into one giant prompt.

## Files

- `AGENT_CONTEXT.md`: cross-agent usage rules and sync boundaries.
- `HANDOFF_PROPS.md`: harness props and the prompt future agents should receive.
- `SKILLS_INDEX.md`: readable grouped inventory of local skills and agent instruction files.
- `skill-inventory.json`: machine-readable inventory for syncing, diffing, and automation.

## Refresh

```powershell
powershell -ExecutionPolicy Bypass -File ".\scripts\sync_agent_skill_context.ps1"
```

## External Sync

GitHub sync should use the existing `agent-hub` remote unless a different repository is selected.

Google Drive sync needs an exact destination folder URL or ID before upload.
